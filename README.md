# Regional Integrated Energy Benchmark

**A Geospatially Constrained Benchmark for Joint Construction of Regional Integrated Energy Networks**

A regional electricity, gas, cooling, and communication test system with public geographic and asset inputs, selected networks, and 8760-hour reference results.

## Download

Download **RIES_Benchmark_1.0.0.zip** from **Releases**. It contains the data, computational code, GIS, model parameters, and technical documentation. The automatic Source code download contains the repository files only.

## Use

Extract the archive to a D-drive directory. Open `GIS.html` to explore the system. Read `docs/RIES_Technical_Documentation.pdf` and `docs/USAGE_CN.md` for model details and operation. Python 3.12 and a valid Gurobi license are used for reconstruction and annual evaluation.
